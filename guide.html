BLUEPRINT COMPACT / GUIDE

使い方と仕組み How it works

最初は3ステップだけ。もっと知りたい人向けに、ページ内部の処理も簡単に説明します。 Start with three steps. This page also explains the internal process for anyone who wants to know more.

01 / QUICK USE

簡単な使い方 Simple usage

01

ノードをコピーCopy nodes

Unreal EngineのBlueprint・Material・PCGで、変換したいノードを選択してCtrl + C。種類は自動で判別します。Select nodes in an Unreal Engine Blueprint, Material, or PCG graph and press Ctrl + C. The graph type is detected automatically.

02

ボタンを押すPress the button

Blueprint Compactを開き、大きなボタンを押します。クリップボードから自動で読み取ります。Open Blueprint Compact and press the large button. It reads the clipboard automatically.

03

AIへ貼り付けPaste into your AI tool

変換されたJSONが自動でコピーされます。そのままAIの入力欄へCtrl + V。The converted JSON is copied automatically. Paste it into your AI tool with Ctrl + V.

別のノードを続けて変換するには？Want to convert another set? Unreal Engineで別のノードをコピーし、結果画面の同じ大きなボタンを押してください。画面を戻る必要はありません。 Copy another set of nodes in Unreal Engine, then press the same large button on the result screen. No need to go back.

02 / INTERNAL FLOW

内部で起きていること What happens inside

ノードの元データはブラウザ内で処理します。MaterialのExpressionやPCGのSettingsなど、入れ子の情報も所有するノードごとに整理します。 Node data is processed inside your browser. Nested Material expressions and PCG settings are organized under their owning nodes.

01

読み取りRead

ボタン操作をきっかけに、ブラウザのClipboard APIからテキストを読み取ります。The button triggers the browser Clipboard API to read the text.

02

解析Parse

Unreal EngineのBegin ObjectやPin情報を見つけ、ノード・ピン・接続関係に整理します。It finds Unreal Engine object and pin information, then organizes nodes, pins, and connections.

03

整理Filter

Compact／Standard／Fullの設定に合わせて、出力する情報を選びます。The selected Compact, Standard, or Full preset determines which information remains.

04

出力・コピーExport and copy

JSONまたはMarkdownへ変換し、AI向け説明文を加えてクリップボードへ保存します。同じ内容を画面にも表示します。It exports JSON or Markdown, adds a short AI context, copies it to the clipboard, and shows the same result on screen.

03 / SUPPORTED GRAPHS

対応範囲と注意点Support and limitations

BP

Blueprint

ノード・ピン・デフォルト値と、実行線・データ線を整理します。Extracts nodes, pins, defaults, execution wires, and data wires.

MAT

Material / Material Function

Expression、パラメータ、テクスチャ・関数の参照と接続を抽出。Named Rerouteの宣言先は、線とは別のreferencesに残します。Extracts expressions, parameters, texture/function references, and wires. Named Reroute declarations are recorded in references, separately from pin wires.

PCG

PCG

入出力・接続・Settings・ユーザーパラメータを抽出。内部のMesh Selector等も階層付きで残します。依存関係はdependencyとして区別します。Extracts inputs, outputs, wires, settings, and user parameters. Nested components such as mesh selectors retain their hierarchy. Dependency-only wires are marked as dependency.

コピー範囲の要約ですA summary of your selection 参照先アセットの内部や、コピーに含まれない既定値は取得できません。設定値はUnrealのテキスト表記で保持します。完全保存やUnrealへの再貼り付け用ではありません。Niagara等はピン付きテキストの汎用抽出のみで、未検証の警告を表示します。対応済みの種類でもエンジンのバージョンやノードによって差があります。 Referenced asset internals and defaults absent from the clipboard are unavailable. Property values retain Unreal's serialized text syntax. This is not a lossless backup or a format for pasting back into Unreal. Niagara and other graph types only use generic extraction of pin-based text, with an unverified warning. Engine versions and node types may vary even for supported graphs.

04 / PRIVACY

データの扱い Data handling

ノードの内容はサーバーへ送信せず、保存もしません。変換中は現在のページのメモリ上だけで扱います。言語や設定だけは、この端末のlocalStorageに保存されます。 Node content is not uploaded or saved. During conversion it exists only in the current page memory. Only language and interface settings are saved in this device's localStorage.
