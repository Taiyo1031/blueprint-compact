BLUEPRINT COMPACT / GUIDE

使い方と仕組み How it works

最初は3ステップだけ。もっと知りたい人向けに、ページ内部の処理も簡単に説明します。 Start with three steps. This page also explains the internal process for anyone who wants to know more.

01 / QUICK USE

簡単な使い方 Simple usage

01

ノードをコピーCopy nodes

Unreal EngineのBlueprintで、変換したいノードを選択してCtrl + C。In an Unreal Engine Blueprint, select the nodes you want and press Ctrl + C.

02

ボタンを押すPress the button

Blueprint Compactを開き、大きなボタンを押します。クリップボードから自動で読み取ります。Open Blueprint Compact and press the large button. It reads the clipboard automatically.

03

AIへ貼り付けPaste into your AI tool

変換されたJSONが自動でコピーされます。そのままAIの入力欄へCtrl + V。The converted JSON is copied automatically. Paste it into your AI tool with Ctrl + V.

別のノードを続けて変換するには？Want to convert another set? Unreal Engineで別のノードをコピーし、結果画面の同じ大きなボタンを押してください。画面を戻る必要はありません。 Copy another set of nodes in Unreal Engine, then press the same large button on the result screen. No need to go back.

02 / INTERNAL FLOW

内部で起きていること What happens inside

Blueprintの元データをそのまま送信するのではなく、ブラウザ内で順番に処理しています。 The original Blueprint data is processed step by step inside your browser instead of being uploaded.

01

読み取りRead

ボタン操作をきっかけに、ブラウザのClipboard APIからテキストを読み取ります。The button triggers the browser Clipboard API to read the text.

02

解析Parse

Unreal EngineのBegin ObjectやPin情報を見つけ、ノード・ピン・接続関係に整理します。It finds Unreal Engine object and pin information, then organizes nodes, pins, and connections.

03

整理Filter

Compact／Standard／Fullの設定に合わせて、出力する情報を選びます。The selected Compact, Standard, or Full preset determines which information remains.

04

出力・コピーExport and copy

JSONまたはMarkdownへ変換し、AI向け説明文を加えてクリップボードへ保存します。同じ内容を画面にも表示します。It exports JSON or Markdown, adds a short AI context, copies it to the clipboard, and shows the same result on screen.

03 / PRIVACY

データの扱い Data handling

Blueprintの内容はサーバーへ送信せず、保存もしません。変換中は現在のページのメモリ上だけで扱います。言語や設定だけは、この端末のlocalStorageに保存されます。 Blueprint content is not uploaded or saved. During conversion it exists only in the current page memory. Only language and interface settings are saved in this device's localStorage.
